Below is a walkthrough of how to use Javascript and Node

What is Node

A dane, Lars Bak, developed the v8 Javascript engine, which ran at imence speeds. Google would use that engine to build the browser. At that time, javascript was primarily utilized in the browser. Some developers wanted to run javascript outside the browser, which is where node.js was conceptualized. Node can run Api's, desktop apps, cli's, scripts and much more, in the javascript language.

How to use Node

To use Node, you must first download it. This can be acomplised at their own site: https://nodejs.org/en/download. On the site there is also a turtorial for downloading downloading the npm, which stands for node package manager. This is essential as it provides access to packages (containing code that serve a goal) developed by others. An example of a popular package is express, which is a server framework. We will use express later to help create an api. This guide is based on Node version 24.

When you have installed Node, you should have access to node in a terminal. When using windows open powershell or git bash, then type node -v.

This will dislpay the version you of Node you are using, and ensures the program is installed. From here create or choose a folder for a project. In this folder create a file, with the extension .js. (like app.js). In this file you can now write a script with javascript.

To run the script use a terminal and type node "filename" .

Javascript turtorial

Javascript is a language historically used in the browser. This is because javascript used to only run in the browser with engines such as the v8. Some languages compile to a binary file that can be executed, others again like Java is compiled to jar, and run in the java virtual machine. The browser or node can interprete javascript, and are required for this turtorial

To write to a console with javascript, you can utilize the javascript object console, and call the method log() on it. log() accepts a string as an argument.

log() can also accept multiple string arguments

If you wanted to print a variable you had stored, which methods should you use? The answer is calling log() with multiple arguments. The reason for this answer is that javascript will see you trying to concatinate a non string argument to a string, and will attempt to transform the data to a datatype that can be concatinated to a string using coercion. This action will mutate the data, which could have unintentional sideeffects.

Speaking of datatypes, Javascript has 8 kinds

  • string
  • boolean
  • number
  • object
  • bigint
  • undefined
  • null
  • Symbol

It is worth noting that javascript is dynamically typed, meaning that a variable only has a type, when it is assigned. A javascript variable can also hold different types. If a variable starts by being assigned a string it can later assigned a number.

Assigning a variable

To assign a variable i javascript type the keyword const, then any name of your chosing, then use the = operator and then type in a value (We will just type ? for now). You can then optionally type a ; to indicate that the declaration is over. The most importan part is to be consistant. For this turtorial there will be ;

Numbers

One of the types of value a variable can store is numbers. Javascript has only one datatype for storing numbers, and wil therefore store all numbers as floating points. This means it is possible to hold both integers and decimal numers within this type.

There are some keywords that also have the type numbers. Not a number NaN, infinity Infinity and negative infinity -Infinity

Sometimes you may want to store larger decimal points, to achieve this it is possible to use the siantific notaion e..

Strings

A string is a datatype that holds text. An example could be a persons name, a cityname or perhaps some userinput. You can assign a string to a variable using the following operators "", '', or ``.

By default you should use "" or '', given that `` has more functionalities such as intepolation and and multiline text. This feature makes `` more versitile in some senarios, which also results in slightly slower compile time. The operators "" and '' are essentially identical. To use the characters " or ' in a string. One solution is to use the other character to encase the string. Otherwise it is possible to use tha escape character \ followed by the quote you wish to escape.

The backsticks operator `` can also be used to make strings. This operator is more powerfull than double " and single ' quotes.

One feature is multiline texts. You can create a variable consisting of multiple lines, where line breaks are conserved.

The backsticks operator has another higly used feature called string interpolation. String interpolation allows one to insert values directly in the string assignment. You insert a value using ${name of variable or just a value}

Boolean

Javascript has a type for storing boolean values, so true and false. This is useful for binary variables, and evaluations of expressions

Bigint

Sometimes you may wish to store larger numbers. For this purpose, javascript provides the datatype bigint.

Null

Javascript provides the datatype null, for any empty value.

Undefined

Javascript also provides Undefined as opossed to null. Undefined is used when you wish to store a value, but do not even know the datatype you wish to store.

Symbol

The symbol datatype from javascript is a unique identifier. It is often used as ids. When using Node you will often use other developers code, to avoid overiting identifiers used by other developers, one can use the symbol type.

Object

To assign a javascript object to a variable, we can use curly brackets { ... }, Whereing we can define some properties. properties are key-value pairs. A key-value pair consists of a key and a saved value, almost like a variable name that is assigend a value. The key is often named to descripe what value is saved, whilst the value is the operand you wish store, and perhaps manipulated. An example of an object could be a user, with a username, email and an id. Another example could be a plant, which could contain many properties such as, coloqial name, latin name, life cycle, watering frequency, max height and whatever else could be relevant.

The Javascript object looks very similar to JSON notaion. The difference is that the keys are not surrounded by "", in Javascript objects. (It is also possible to write comments inside a javascript object, which is not allowd in JSON)

The typical use of objects is to store related data together. To access the saved values we can dot into the objects keys

An object can store any datatypes, including other objects. To access such values, one must dot into both objects, like a chain of dots.

It is also possible to add new key-value pairs to an existing object This is achieved almost the same as accessing properties, by trying to access a key that does not exist yet.

More about const

const is short for constant, but it is not as simple as the value can never be changed, just that the variable is contant in the assignment. The value is still mutable, so it is still possible to mutate the data within value, but it is not possible to reassign the value.

There used to be a different keyword to const and let, called var. But the use of var has been discontinued in modern development, and let is its replacement. (The reason is that var is hoisted to the top and assigned undefined. This caused confusing behavoir when developing, as undefined can be used by developers on purpose. So why does the var keyword even exist anymore? Javascript has a philosophy that no feature is ever removed, making it always backwards compatible. This was probably due to javascripts use primarily for websites, so the philosophy ensures that websites do not need extra maintinance after creation)

This will result in a new file to be generated by node pacage manager named package.json. This file predictally contains JSON notaion, which looks similar to javascript pbjects.

As seen in the file-system above, there are acually two files generated package.json and package-lock.json

package.json contains meta-data about the project, and will in our case look like the following file:

package-lock.json contains data about the exact version each dependency may have. This is meant to ensure that everyone with this file, will have the exact same dependencies and avoid "Works on my maschine" issues.

package.json is a file like any other, and can be manually written. You could delete the file in your project, and write it from scratch yourself. The important part i that the name is exactly the same and that the code is written using JSON notaion, and contain recognized keys (like "dependencies").

As stated earlier package.json should contain metadata, and a project often contains more metadata than dependencies. It is possbile to manually write this data, but there is also a way to save yourself some time.

A better start to a Node project

The Node package manager can help you start your project with the command init, that generates a package.json file, with relevant meta-data from your terminal.

This command will generate the package.json file. But we are still missing the package-lock.json file. The same wil be true if you manually write the package.json file. To generate the missing file type into your terminal npm install.

The command will install all dependencies from the "dependencies" key inside package.json. Generating the file with npm init will not add the dependencies field, so be sure to add it manually, in our case just express
